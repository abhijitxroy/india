## Simple Classification

| Category | Examples |
|---|---|
| Ballistic missiles | Agni, Prithvi, K-Series |
| Cruise missiles | BrahMos, Nirbhay |
| Air-defence missiles | Akash |
| Missile defence | Ballistic Missile Defence |
| Long-range air defence | S-400 |
| Nuclear deterrence | Nuclear Triad, Agni, K-Series |
| Space capability | ASAT, military space systems |
| Advanced weapons | Hypersonic programmes |

## Learning Order

1. Understand ballistic vs cruise missiles
2. Learn Prithvi and Agni
3. Learn BrahMos and Nirbhay
4. Learn K-Series and submarine-launched missiles
5. Understand the Nuclear Triad
6. Understand Akash and S-400
7. Understand Ballistic Missile Defence
8. Learn India's space and ASAT capability
9. Study India's future hypersonic programmes
