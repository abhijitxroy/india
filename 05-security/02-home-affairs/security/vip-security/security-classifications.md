# Security Classifications in India

## Overview

India provides security protection to individuals who face potential threats to their lives. Security cover is granted after threat assessments conducted by intelligence and security agencies.

The level of protection depends on threat perception rather than political position, social status, or public popularity.

## Quick Facts

| Item | Details |
|----------|----------|
| Purpose | Protection against security threats |
| Deciding Authority | Ministry of Home Affairs and State Governments |
| Assessment Agencies | Intelligence Bureau, State Intelligence Units, Police Agencies |
| Common Categories | X, Y, Y+, Z, Z+ |
| Special Category | SPG Protection |
| Basis | Threat Perception and Security Assessment |

## Why Security Categories Exist

Security resources are limited and must be allocated according to the level of risk faced by an individual.

The classification system helps ensure that people facing higher threats receive greater protection while allowing security agencies to use resources efficiently.

## Security Categories

### X Category Security

X Category is the basic level of VIP security.

#### Typical Features

- Small security team.
- Armed personnel when required.
- Protection based on assessed risk.

#### Usually Given To

- Individuals facing limited but credible threats.
- Public figures requiring basic protection.

### Y Category Security

Y Category provides a higher level of protection than X Category.

#### Typical Features

- Larger security team.
- Multiple security personnel.
- Enhanced protection arrangements.

#### Usually Given To

- Public officials.
- Political leaders.
- Individuals facing moderate threats.

### Y+ Category Security

Y+ Category is an enhanced version of Y Category security.

#### Typical Features

- Increased number of security personnel.
- Greater protection during travel and public appearances.

#### Usually Given To

- Individuals with elevated threat perception.
- Senior public figures.

### Z Category Security

Z Category provides a high level of security cover.

#### Typical Features

- Large security team.
- Continuous protection arrangements.
- Security planning for public events and travel.

#### Usually Given To

- Senior political leaders.
- High-profile individuals facing serious threats.

### Z+ Category Security

Z+ Category is among the highest levels of VIP protection.

#### Typical Features

- Extensive security coverage.
- Multiple layers of protection.
- Advanced security coordination.

#### Usually Given To

- Individuals facing very high security threats.
- National-level leaders and other high-risk protectees.

## Special Protection Group (SPG)

SPG protection is separate from the normal X, Y, Y+, Z, and Z+ classification system.

It is governed by specific legal provisions and is primarily associated with the protection of the Prime Minister.

## Who Can Receive Security Cover

Security protection may be provided to:

- Prime Minister
- Former Prime Ministers
- Chief Ministers
- Governors
- Union Ministers
- MPs
- MLAs
- Judges
- Religious leaders
- Witnesses facing serious threats
- Public figures and other individuals facing verified risks

Receiving security cover depends on threat assessment rather than office alone.

## Historical Significance

India's security classification system developed to provide structured protection based on risk and intelligence inputs.

The system helps balance public safety, resource allocation, and security requirements.

## Quick Revision

- Security cover is based on threat perception.
- X is the basic protection category.
- Y and Y+ provide enhanced protection.
- Z provides high-level protection.
- Z+ provides very high-level protection.
- SPG protection is separate from normal categories.
- Intelligence agencies regularly review threat assessments.
- Security cover can be upgraded, downgraded, or withdrawn.
