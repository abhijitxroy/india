# VIP Security

## Overview

VIP security refers to the system of security protection provided to individuals facing potential threats to their lives. In India, security cover is granted based on threat assessments conducted by intelligence and security agencies.

Security protection is not automatically linked to political position, wealth, or public status. It is primarily based on threat perception and security reviews.

## Quick Revision

- VIP security is based on threat assessment.
- Security cover can be increased or reduced.
- X, Y, Y+, Z, and Z+ are common security categories.
- SPG provides protection to the Prime Minister under applicable law.
- Intelligence and security agencies review threat perceptions.
- Security is not automatically granted because of political office.
- Different agencies may provide different layers of protection.
