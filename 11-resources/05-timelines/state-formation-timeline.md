
# State Formation Timeline

## Overview

This timeline explains how India's states and union territories evolved after Independence.

The objective is to help readers understand the development of India's federal structure, linguistic reorganization, territorial changes, and the creation of new states.

---

## Historical Significance

Understanding state formation helps explain:

- How India's federal system evolved
- Why states were reorganized
- How linguistic and regional identities influenced governance
- How administrative efficiency improved over time
- How the Union and states function together

---

## State Formation Timeline

| Year | Event | Significance |
|----------|----------|----------|
| 1947 | Independence | Integration of provinces and princely states begins |
| 1950 | Constitution Comes Into Force | States formally become part of the constitutional framework |
| 1956 | States Reorganisation Act | Major linguistic reorganization of states |
| 1960 | Maharashtra and Gujarat Created | Bombay State divided |
| 1963 | Nagaland Created | New northeastern state formed |
| 1966 | Haryana Created | Punjab reorganized |
| 1972 | Meghalaya, Manipur, Tripura Become States | Expansion of statehood in Northeast India |
| 1975 | Sikkim Becomes a State | Integration into the Indian Union |
| 1987 | Goa Becomes a State | Statehood granted to Goa |
| 2000 | Chhattisgarh, Jharkhand, Uttarakhand Created | New states formed for administrative and regional reasons |
| 2014 | Telangana Created | Newest state formed through reorganization |
